## Hey, I'm Jebarson Immanuel

Cybersecurity undergraduate at **SRM Institute of Science and Technology**, Chennai — specializing in Networking & Communications. I break things to understand how they work, build tools to automate what's tedious, and occasionally write about it.

Currently focused on **offensive security**, **SIEM engineering**, and **bug bounty hunting**.

---

### What I work on

**Security Tooling** — Building custom scanners, parsers, and dashboards that solve real problems in security operations. Most of my tools are built to run headless on Linux and serve results through web dashboards.

**Bug Bounty** — Active on HackerOne and Bugcrowd. I hunt for exposed infrastructure, misconfigurations, and access control flaws across public programs.

**Research** — Published an IEEE paper on endpoint-centric risk scoring for SOC environments using Wazuh. The system replaces flat alert queues with cumulative, per-endpoint threat indexes.

### Projects

| Project | Description |
